1指令备注与基本约定

指令备注说明：默认基站和终端都适用，特殊指令标注如下：

标注含义
*只作用终端
◆只作用基站

附录：AT 指令说明

本手册中所有命令行必须以“AT”作为开头，以回车换行（<CR><LF>）作为结尾。只有在 AT（配置）模式才能响应指令，否则模块将处于透传模式。指令响应格式为 <CR><LF>响应内容<CR><LF>。

本手册中只有 <响应内容> 被介绍，<CR><LF> 被有意省略。<响应内容> 和设置参数值 <x> 为十六进制字符串。设备串口支持多种波特率，网关默认使用 115200，终端默认使用 9600，8 位数据位，无校验位，1 位停止位。

在 AT 配置模式下，每一条 AT 指令都有回响，用户使用时须等待指令回响结果再做下一步操作。如果命令执行失败，响应对应错误代码。

常见错误代码

代码含义代码含义
ER00语法错误ER05保存失败
ER01参数错误ER06缓冲区满
ER02执行失败ER07发送超时
ER03信道忙ER08命令不支持
ER04长度错误ER09不可读

2AT 模式与短指令

AT 模式：可由 ++ 指令进入或引脚 AT 口拉高进入，建议使用指令切换方式，AT 口不用可悬空或拉低处理。

当模块 AT 脚置低或悬空时，发送特殊字符“+++”（无需回车结尾），可使模块进入配置模式。如需退出配置模式，可使用“ATT”指令。

命令语句回响内容说明
+++OK网关进入配置模式
ATOK查询是否支持 AT 命令
ATI+ATI:<version 1>, <version 2>查询设备版本信息，Version 1 为硬件版本，Version 2 为软件版本。GW1 显示两行，GW1P、GW2 或终端只有一行
ATZOK恢复默认参数，终端模组恢复后会自动重启设备
ATROK软件复位，模块重启
ATTOK退出配置模式进入透传
ATH示意如下查询所支持的 AT 命令，不同产品及版本支持数量有差异

4设置指令

以下指令 <x> 用于代表配置参数，为十六进制（hex）格式字符串，具体内容请参考说明或示例。

命令语句回响参数说明
AT+NET=<x>（*）OK网络模式：00 定频模式 / 01 跳频模式。定频用于点对点测试，跳频用于点对基站通信
AT+AID=<x>OK8 字节十六进制，LoRaWAN 模式下用作 AppEUI 或 JoinEUI
AT+AK=<x>OK16 字节十六进制，配置 AES 密钥。默认未配置，配置后自动开启 AES，配置全 0 关闭
AT+ADDR=<x>OK4 字节单播地址，默认取自模块 ID 后 4 字节，建议不要修改
AT+MADDR=<x>（*）OK4 字节组播地址，默认取自模块 ID 前 4 字节，可实现模块分组接收
AT+MODE=<x>OK调制方式：00 FSK / 01 LoRa
AT+TPREM=<x>OK发送前导码，默认 0008
AT+RPREM=<x>OK接收前导码，默认 000A
AT+LDR=<xy>OK低速率优化，x 高 4bit 为发送 LDR，y 低 4bit 为接收 LDR。0 AUTO / 1 全部开启 / 2 全部关闭。收发两端必须一致
AT+SYNC=<x>OK同步字，默认 0x12，收发两端必须一致
AT+SYWD=<x>OK同步字，可配置 1~4 个字节
AT+POW=<x>OK发射功率值（十六进制），14 对应 20dBm
AT+BW=<x>OK带宽：07 125K / 08 250K / 09 500K
AT+CR=<x>OK编码率：01 4/5 / 02 4/6 / 03 4/7 / 04 4/8
AT+TFREQ=<x>OK发送频点，示例 1E3093A0 对应 506.5MHz
AT+RFREQ=<x>OK接收起始频点，4 字节 8 字符，每个频点间隔 200KHz，总计 8 个频点
AT+FREQA=<x>（◆）OK通道 A 起始频点，每个频点间隔 200KHz，总计 4 个频点
AT+FREQB=<x>（◆）OK通道 B 起始频点，每个频点间隔 200KHz，总计 4 个频点。需将默认接收频点配置为 0 才能使用
AT+TSF=<x>OK发送扩频因子，0C 对应 SF12
AT+RSF=<x>（*）OK接收扩频因子，0C 对应 SF12
AT+TIQ=<x>OK发送载波反转：00 不反转 / 01 反转。收发反转配置必须一致
AT+RIQ=<x>OK接收载波反转：00 不反转 / 01 反转
AT+SIP=<x>OK序号及协议功能：00 默认 / 01 私有协议 / 10 包序号功能 / 11 包序号及私有协议 / 02 LoRaWAN ABP / 03 LoRaWAN OTAA。高 4 位为 SEQ 功能，低 4 位为 IP 功能
AT+RGN=<x>OK地区规范：00 无 / 01 EU868 / 02 US915 / 03 CN779 / 04 EU433 / 05 AU915 / 06 CN470（国内默认）/ 07 AS923 / 08 KR920 / 09 IN865 / 0A RU864 / 0B LA915
AT+SEN=<x>OK传感器类型，用于 DT2xx/4xx 二次集成设备：00 未指定 / 01 0~5V / 02 4~20mA / 03 温湿度 / 04 PT100 / 05 DS18B20 / 06 K 型热电偶 / 07 NTC 测温 / 08 红外测温 / 09 水浸 / 0A I/O 门磁 / 0B 震动 / 0C 倾角 / 0D 压力
AT+URC=<x>OKURC 输出控制：00 禁止（默认）/ 01 开启
AT+FPORT=<x>OKFPort 值，主要用于 LoRaWAN，有效范围 0x01~0xDF
AT+ACK=<x>（*）OK模块应答开关：00 不应答（默认）/ 01 应答。暂只针对透传模式且需开启 IP 功能
AT+BRATE=<x>OK串口波特率：00 1200 / 01 2400 / 02 4800 / 03 9600（默认）/ 04 19200 / 05 38400 / 06 57600 / 07 115200（网关默认）/ 08 230400 / 09 460800
AT+PAR=<x>OK串口奇偶校验：00 None / 01 Even / 02 Odd
AT+TYPE=<x>OK基站数据格式：00 SIMPLE 透传 / 01 TLV / 02 FRAME / 03 JSON / 04 TLV V1 定制版本

5数据发送与接收

AT+TX 发送数据

除透传方式外，还可使用 AT 命令发送数据。为匹配 ASCII 命令格式，发送数据需将每个字节的 ASCII 码转成十六进制字符串。

命令语句回响说明
AT+TX=<x>OK<x> 为数据内容（十六进制）。如 AT+TX=123456 发送 0x12,0x34,0x56。成功返回 OK，失败返回错误码
AT+RX=<x>OK00 关闭接收 / 01 开启接收测试模式。主要用于性能测试，配置不保存，复位后关闭。基站为工厂测试模式，打印 FRAME 格式
AT+TXF=<x>OK按频点发送数据，在数据最前面增加 4 字节频点 HEX 字符串。如 AT+TXF=1E3093A0123456 表示在 506.5MHz 发送 0x12,0x34,0x56。该频点只临时作用于当次发送，不保存

6低功耗与链路参数

命令语句回响说明
AT+LCP=<x>OK链路检测周期，2 字节十六进制，单位秒，设置为 0 则不开启。基站用于 1301 检测周期；终端模组为休眠周期，休眠周期到开启 LoRa 信号监测用于空中唤醒。示例 0708 即 1800 秒
AT+LFT=<x>（◆）OK存活周期，2 字节十六进制，单位秒，设置为 0 则不开启 Life Time 检测
AT+LAT=<x>（◆）OK设置纬度，4 字节浮点数十六进制字符串。如 41E1DA2D 对应 28.23153
AT+LGT=<x>（◆）OK设置经度，4 字节浮点数十六进制字符串。如 42EA1252 对应 117.03578
AT+EL=<x>（*）OK休眠时间，2 字节十六进制，如 0020 为 32 秒，最长 12 小时 A8C0。0000 为长期低功耗模式。参数配置不保存，重启失效
AT+PARAM=<x>（*）OK扩展参数，备用命令，定制化需求使用，最多 16 字节（32 字符）
AT+CMD=<x>（*）OK扩展命令，备用命令，定制化需求使用
AT+TFIX=<x>（*）OK固定发送长度，1 字节十六进制，设置为 0 则不固定。使用 SF6 收发时必须固定长度（HL9、KL9 127x 系列）
AT+RFIX=<x>（*）OK固定接收长度，1 字节十六进制，设置为 0 则不固定。使用 SF6 收发时必须固定长度
AT+FNB=<x>（*）OK退避策略，1 字节十六进制。bit7 表示退避失败是否强制发送（0 丢弃 / 1 仍发送），bit6~0 为退避次数，系统默认 4 次
AT+RXW=<x>（*）OK接收窗口时间，1 字节十六进制，单位秒，需配合 LCP 配置使用
针对 HL9 模组，LCP 与休眠不能同时配置。由于 HL9 支持低功耗串口，在波特率 9600 及以下可由串口直接唤醒模组，因此 <= 9600 暂不支持 AT+EL 命令。

84G 相关指令

4G 相关指令采用十进制或字符串方式，兼容原 PC100C1 终端指令。

命令语句回响说明
AT+SERV=<idx>,<host>,<port>OK设置服务器地址信息。
idx 服务器序号，目前固定为 0，只支持连接一个服务器
host 服务器地址，可以是 IP 或域名，不超过 60 字符
port 端口号 1-65535
示例：AT+SERV=0,114.221.142.25,60000
AT+APN=<apn>OK设置 APN，字符串不超过 30 字符。一般不需要手动设置，设备会根据卡类型自动获取 APN，示例 AT+APN=ctnet
AT+WAY=<way>OK设置通信方式，十进制数，取值 0/1/2，分别为 UDP、TCP、MQTT。示例 AT+WAY=2 表示 MQTT
AT+SIM=<sim>OK选择卡槽，十进制数，取值 0/1，分别为卡槽 1 和卡槽 2。默认卡槽 1，双卡槽版本可按需设置
AT+TOPIC=<topic>OK设置 MQTT 的 Topic 前缀，不超过 30 字符。设备会自动补全设备编号和数据分类，形成完整 Topic
AT+USPD=<uname>,<passwd>OK设置 MQTT 用户名和密码，均为字符串，各自不超过 30 字符，示例 AT+USPD=wwiot,wwiot
AT+CLID=<clientid>OK设置 MQTT 的 ClientID，不超过 30 字符。默认使用设备编号的后 8 位字符串，可按需修改
AT+OPT=<opt>OK是否默认服务器，十进制数，取值 0/1，分别为自定义和固定服务器。一般不需要设置，默认为自定义服务器

MQTT Topic 补全规则

此处配置的 Topic 为前缀部分。以设备编号 3000100F、前缀 wwiot/devices 为例，采用 MQTT 通信时主要分为 3 个 Topic：

用途Topic
数据上报wwiot/devices/3000100F/data
终端应答wwiot/devices/3000100F/ack
订阅下行wwiot/devices/3000100F/dw

9DTU 采集指令

采集指令相关，支持自定义和复合类型。

命令语句回响说明
AT+REGS?+REGS:num查询采集指令，num 为采集指令数量。num 不为 0 则继续列出对应的采集指令
AT+AREG=<index>,<param1>,...,<paramN>OK添加采集指令。index 为指令索引号，取值 0~59，即最大 60 条；param 个数根据设备指令类型，分别为 1 个（自定义类型）和 4 个（复合类型）
AT+DREG=<index>OK删除采集指令。index 为指令索引号，取值 0~59
