1 产品概述

WW-G2 是一款工业级 LoRaWAN 网关，核心采用 SX1302 LoRa 基带模组，支持面向全球不同地区的 LoRaWAN 频段配置；针对中国市场，还可支持 LoRa 私有协议。设备集成内置 NS（Network Server），可在边缘侧完成终端接入与数据汇聚，并通过 MQTT、HTTP、TCP 或 UDP 将数据转发至业务平台。

面向智慧园区、工业采集、能源与城市物联网场景，融合 LoRa、4G、Wi-Fi 与双以太网通信，提供内置网络服务器与多协议数据转发能力。

RF多无线制式
支持 4G、Wi-Fi 与 LoRa，适配有线网络受限或需要冗余链路的现场。
NS边缘网络服务器
内置 NS，可就地管理 LoRaWAN 终端并完成数据处理与转发。
↔工业协议衔接
具备 RS485 接口，并支持 Modbus 协议数据转发，便于接入仪表与控制设备。

链路说明

  • LoRaWAN 终端通过标准 LoRaWAN 链路接入内置 NS。
  • 国内私有 LoRa 设备按项目协议与频点配置接入。
  • RS485 设备通过 Modbus 协议采集并转发。
  • 上行可选以太网、4G 或 Wi-Fi，具体主备策略以软件配置为准。
  • 数据可按平台要求选择 MQTT、HTTP、TCP 或 UDP。
  • 双网口可用于现场网络接入或分区组网，功能以固件版本为准。

5 接口与安装

安装位置

  • 选择通风、牢固且便于维护的位置，使用背部壁挂孔可靠固定。
  • 远离强电磁干扰源、大面积金属遮挡及持续高温热源。
  • 设备采用内置天线，应保持壳体周围无遮挡，避免紧贴金属柜体或大型金属构件。
  • 若部署于户外，应确认整机防护等级并做好底部 PG 接头防水、避雷与接地。

结构方向

设备竖直壁挂安装时，四个 PG 防水接头位于机壳底部并朝下，有利于线缆自然下垂和降低雨水沿线缆进入接头的风险。正面为无螺丝的一体化盖板；维护拆装方式应以量产结构和售后指引为准。

推荐接线顺序

  1. 断电操作：确认电源断开，核对输入为 9–36V DC，并检查极性。
  2. 连接通信线：线缆从机壳底部向下进入 PG 接头；按项目需要连接以太网及 RS485，RS485 总线应注意 A/B 极性、终端匹配与屏蔽接地。
  3. 紧固 PG 接头：确认线径与密封圈匹配，逐一锁紧接头，并预留向下的滴水弯，避免线缆受力传递到接口。
  4. 连接电源：完成线缆固定与绝缘检查后再上电，避免带电插拔裸线端子。
  5. 观察启动状态：等待设备完成启动，通过状态指示或管理界面确认系统、网络及 LoRa 服务正常。
重要：不得在壳体上自行加装外置天线或钻孔，以免影响内置天线性能和整机密封。电源必须位于 9–36V DC 范围内。

6 首次配置

快速启用流程

  1. 接入管理网络：使用以太网或设备支持的本地管理方式连接网关。默认地址、账号与初始密码应以产品标签或随箱配置卡为准。
  2. 配置上联网：选择以太网、4G 或 Wi-Fi，设置 IP、APN 或无线网络参数，并验证 DNS 与目标平台可达。
  3. 配置 LoRa 参数：选择部署地区对应的频段与信道计划；按终端类型启用 LoRaWAN 或中国市场私有 LoRa 协议。
  4. 配置 NS 与终端：在内置 NS 中创建应用并登记终端身份与密钥。密钥应通过安全渠道导入，不应出现在截图或公开文档中。
  5. 建立数据转发：选择 MQTT、HTTP、TCP 或 UDP，填写服务器地址、端口、主题或接口路径及鉴权信息；如需采集 RS485 设备，再设置 Modbus 串口与寄存器映射。
  6. 联调验收：检查终端上线、无线信号、数据时间戳、断线重连、缓存补传及平台解析结果，并保存配置备份。

现象建议检查
