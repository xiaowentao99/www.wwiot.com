2接口概述

2.1 全局说明

本协议为 LPWAN 采集方案制定，主要针对各类传感器数据采集应用定制。通信方式为 LoRa 无线通信；字节序为多字节统一大端模式（网络字节序）。

2.2 基本约定

数据传输全部采用二进制字节流方式，字节序为大端模式。

类型含义类型含义
uint8_t无符号 1 字节整型int32_t有符号 4 字节整型

3传感设备 TLV 格式

3.1 整体报文格式

适用于最新 GL6xx 网关方式采集数据，区别于之前 GW 系列网关，简化下行控制，使模组上下行风格保持一致。以下为网关实际收到的内容或下发内容格式。

Message PreambleMessage BodyMessage CRC
Header(1 Byte) + DevAddr(4 Bytes) + FCtrl(1 Byte) + SeqNo(2 Bytes)N 个传感器数据（Data1…DataN）CRC(2 Bytes) = Message Header + Message Body

Message Body 采用类似 TLV（Type + Length + Value）风格。为节约带宽功耗，部分类型省略了长度（Length）字段。

Header DevAddr FCtrl SeqNo Data1 ... DataN CRC 1 字节 4 字节 1 字节 2 字节 数据1 ... 数据N 2 字节 协议头 设备地址 控制字 包序号 TLV ... TLV CRC16 = Header 至 DataN

4.4.4 地理坐标（0x02）

经度 float32_t + 纬度 float32_t。示例 02 42 ED 61 A3 42 00 7E 6A，经度 0x42ED61A3，纬度 0x42007E6A，对应 float 值 32.12345。

4.4.5 采样数据（0x03）

2 字节无符号整型，具体含义可根据项目而定。

4.4.6 温度（0x04）

2 字节有符号整型，零下为负值，默认单位 0.1 度，即 201 表示 20.1 度。示例 04 FF 88 表示 -120，即 -12 度。

4.4.7 湿度（0x05）

1 字节无符号整型，默认单位 1%，即 10 表示 10%。

4.4.8 含量（0x06）

1 字节无符号整型，具体含义根据项目而定。

4.4.9 压/拉力值（0x07）

4 字节有符号整型，默认单位 Pa，如果为拉力则单位为 N（牛）。

4.4.10 传感值（0x08）

4 字节 float32_t 型数据，具体含义可根据项目而定。

4.4.11 通用开关量（0x09）

多数情况下一个设备只有 1 路开关量，但满足最多 8 路开关量状态表示。一般单个 bit 位代表一路开关量。如果是阀门控制项目，Value 为阀门开（0x01）和关（0x00）；如果是水浸状态，Value 为有水（0x01）和无水（0x00）。

对于烟雾报警器，每个 bit 位定义如下：

0 / 1正常 / 开机正常 / 激活正常 / 拆除默认正常 / 测试正常 / 低电量正常 / 故障正常 / 报警

4.5 定制化类型详细定义

4.5.1 通信参数（0x10）

读相关项目中通信配置的响应，一般用于旧版本 LoRa 终端设备。Value 按顺序列出：TFREQ 发送频点（uint32_t）、LCP 周期（uint16_t）、RPREM 接收前导长度（uint16_t）、LFT 周期（uint16_t）、TSF 发送扩频因子（uint8_t）。采用 Length 以便自适应无线查询配置。

4.5.2 倾角（0x11）

根据长度适配 N 轴倾角，N=1 上报 X 轴，N=2 上报 X 和 Y 轴，N=3 上报 X、Y、Z 轴。每轴 int32_t，单位 0.001°。

4.5.3 多路温湿度（0x12）

根据长度适配 N 路温湿度，数据分辨率 0.1。每路为 int16_t 温度 + uint16_t 湿度，Length = 4*N。

4.5.4 多路采样值（0x13）

根据长度适配 N 路采样值，uint16_t，Length = 2*N。如果 N 为 1 可直接使用类型 0x03。

4.5.5 多路温度（0x14）

N 路温度，int16_t，Length = 2*N。如果 N 为 1 可直接使用基础温度类型 0x04。

4.5.6 多路湿度（0x15）

N 路湿度，uint8_t，Length = N。如果 N 为 1 可直接使用基础湿度类型 0x05。

4.5.7 电流电压（0x1A）

根据长度进行扩展，只含电流时 Length 为 2；电流和电压则 Length 为 4。电流单位 mA，电压单位 0.1V。

4.5.8 功率电能（0x1B）

根据长度扩展，只含 P 时 Length 为 4。有功功率 P 单位 W。

4.5.9 仪表地址（0x20）

在万维传感器设备中，此类型用于上报从机地址，以便配套的网关进行 Modbus 协议转换。在其他定制化项目中，一般用于上报仪表地址。如流量计、水表等行业设备中，单个地址一般为 7 字节。在流量计和热表项目中，N 为 14，分别代表流量表地址和热表地址，参考 CJ/T188-2004 格式。

4.5.10 业务数据（0x21）

为上报外接传感器的原始数据而定义，便于用户获取数据长度及对应内容。在某些定制化项目中，传感器侧内容首字节增加一个字节用于区分业务报文：0x00 灯控设备、0x01 网关电能、0x02 热表、0x03 特殊气体、0x04 接地环流、0x05 测控仪表。

4.5.11 Modbus 数据（0x24）

为了区分 Modbus 与非 Modbus 业务，定义 0x24 数据类型，Value 为 Modbus 从机主动上报数据。

4.5.12 用户命令数据（0x25）

为支持用户命令（DT200/400 系列上支持的多条扩展命令）采集数据上行，接收端需要判断该数据为第几条命令所采集的，故在 Value 用户内容前增加 1 个字节，序号从 0 开始。

4.5.13 混合气体类（0x30）

Value 通常为 5 字节：首字节为气体类型，0x01 CH4、0x02 CO、0x03 H2S、0x04 CO2、0x05 NH3，后 4 字节为 int32_t，分辨率统一为 0.01。

4.5.14 带单位的传感器值（0x38）

Value 通常为 5 字节：首字节为单位类型，后 4 字节为 float32_t。单位类型：0 帕 Pa、1 百帕 hPa、2 千帕 kPa、3 兆帕 MPa（默认）、4 PSI、5 PSF、6 kg/cm²、7 mH2O、8 mmH2O、9 bar、10 mbar、11 mmHg、12 inHg、13 标准大气压 atm。

4.5.15 存储记录（0x40）

为支持带存储记录功能设备上报而增加此类型。Value 一般 12 字节：RecordID（uint32_t，记录序号）、YYMMDDhhmmss（6 字节，年月日时分秒，均为十六进制）、Status（2 字节状态信息）。例如 1808100F0003 即 2024-08-16 15:00:03。

4.5.16 公用配置（0x80）

在 4G 终端中一般用于传输 4G 通信参数：服务器地址,端口号,通信方式；MQTT 模式下附加 用户名,密码,clientID,Topic。

4.5.17 用户参数（0x81）

读取用户参数，如周期、校准值、变化量设置。Value 按顺序列出：上报周期（uint16_t）、检测周期（uint16_t）、校准值（int32_t）、变量 1~3（uint8_t）。采用 Length 以便自适应无线查询配置。如 Length 是 4，则只含上报和检测周期；如 Length 是 8，则含上报周期、检测周期和校准值。

5.2.4 下行用户命令（0x21）

Type 0x21，Length 为 N，Value 为 N 字节用户设备指令。终端侧需开启数据报文 TLV 格式（以识别设备 DevAddr），否则将直接转发下行的整个数据包到用户设备上。

5.2.5 开关控制（0x22）

Value 的 bit 位由低到高表示开关状态，xxxx xxx0 为关，xxxx xxx1 为开。如只控制 1 路开关，则 Value=0x01 表示开，Value=0x00 表示关。

5.2.6 多路控制（0x23）

最多支持 8 路开关控制。第 1 字节为开关掩码，bit 为 1 则有效；第 2 字节为开关动作，bit 为 1 则开，为 0 则关。例如 23 0F FC 表示 8 路开关只有 bit3~0 的 4 路有效，且 bit3~2 为开、bit1~0 为关。

6.2 CRC16 代码

本文档使用的 CRC 校验算法如下。

C 语言版本

static uint16_t get_crc16(uint16_t inData, uint16_t outData) { outData = (outData >> 8) | (outData << 8); outData ^= inData; outData ^= (outData & 0xff) >> 4; outData ^= outData << 12; outData ^= (outData & 0xff) << 5; return outData; } static uint16_t cal_crc16(const uint8_t *pData, const uint32_t len) { uint32_t i = 0; uint16_t crc16 = 0xFFFF; for (i = 0; i < len; i++) { crc16 = get_crc16(*(pData++), crc16); } return crc16; }

Java 语言版本

public static int calcRJCRC16(byte[] bytes) { int crc = 0xffff; for (byte seed : bytes) { crc = (crc >>> 8) | (crc << 8); crc ^= seed & 0xff; crc ^= (crc & 0xff) >> 4; crc ^= crc << 12; crc ^= (crc & 0xff) << 5; crc = crc & 0xffff; } return crc; }
