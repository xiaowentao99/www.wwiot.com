## 1 命令格式约定

| 项 | 规则 |
| ---- | --- |
| 进命令态 | 静默 ≥1s → `+++` → 静默 ≥1s → `OK`（默认空密码自动解锁） |
| 退命令态 | `ATO` → `OK`，退回数据模式并上锁 |
| 写 | `AT+KEY=<值>` → `OK`；成功后落盘 |
| 读 | `AT+KEY?` → `AT+KEY=<当前值>` + `OK` |
| 执行 | `AT+XXX`（无参数）或只读查询如 `AT+DOOR?` |
| 失败 | 未知/越界/未解锁 → `ERROR`；**不在本机能力集** → **`ERR3`**（规范口径） |
| 分隔 | 多段一律英文逗号 `,`；射频类空字段 = 不改该项 |
| 通道 | 第 N 段 = 第 N 路；`0` = 关该路；只写前 N 段 = 只改前 N 路 |
| 串口 | LPUART0，115200 8N1，`\r\n` 或 `\n` 结尾 |

**生效时机**：`立即` / `下周期` / `重启`（见各表「生效」列）。

**状态列**：**现行** = 已发布固件；**新增** = 规范新增（旧固件可能 `ERROR`）；**预留** = 能力集未实现，回 `ERR3`。

### 1.1 设计规则（摘自规范）

| # | 规则 |
| - | --- |
| 1 | key 全小写、不超过 4 字符；AT 侧大写同串（`AT+PER=` ↔ `"per"`） |
| 2 | 多段参数一律英文逗号；查询回显与写入格式一致 |
| 3 | 按通道的 key，value 为逗号列表，顺序 = CH1..CHN；0 = 关闭该路 |
| 4 | 只写前 N 段 = 只改前 N 路，后面保持不变 |
| 5 | 不在设备能力集内的 key：AT 回 **ERR3**；远程下发忽略 |
| 6 | 射频类 key（`lora`/`exlora`/`ack`/`batt`）为位置参数，空字段 = 不改该项；另见 `aes`（128-bit 密钥）、`eui`（DevEUI，LoRaWAN） |
| 7 | 注册包配置快照与 AT / 远程下发 **同口径**：AT/远程仍用 key 多段字符串；**空口**用既有 TLV Type（`0x81`/`0x10` 等）承载，见 **§6.6.1**；**勿发明新 Type** |

# 第一部分 · 通用型

## 2.1 通用层（per / var / cal / tun）

| key | AT 指令 | value 格式 | 说明 | 状态 | 生效 |
| --- | --- | --- | --- | --- | --- |
| `per` | `AT+PER=` | `检测秒,发送秒`；`0,0`=关闭周期 | 关闭后仅保留中断（门磁）、按键、`AT+REPORT` | 现行 | 下周期 |
| `var` | `AT+VAR=` | 按通道逗号序，0.01 单位，`0`=关该路 | 温度 0.01℃ / 湿度 0.01%RH；多路按路交替展开 | 现行 | 下周期 |
| `cal` | `AT+CAL=` | 按通道逗号序 | 校准（预留；对齐 LoRaWAN 0x13：温度 0.1℃、湿度 1%RH） | 新增 | 立即 |
| `tun` | `AT+TUN=` | `0`=℃ / `1`=℉ | 温标（预留；对齐 LoRaWAN 0x17） | 新增 | 下周期 |

- `AT+ZERO`（执行）：以**当前采样**为新零点，自动写偏移使当前读数=0；与 `AT+CAL` 互补。只执行、不单独查询；偏移可读 `AT+CAL?`。开关量类不适用。
- **门磁 / 水浸（WW-26L / WW-27L / WW-27L-D 等）无 `AT+VAR` / `AT+CAL` / `AT+ZERO`**（不在能力集则 **ERR3**）；靠 `per`、门磁/水浸中断与 `AT+REPORT`。
- 烟感等纯开关量同理，不以 `var` 做模拟量变化窗。
- **WW-21L 人体感应**带光照/温湿度等模拟量，**需要** `AT+VAR` / `AT+CAL` / `AT+ZERO`（及温标 `AT+TUN`）等传感指令。

```
AT+PER=60,600
AT+VAR=50,200
AT+CAL=-30,150
AT+TUN=0
AT+ZERO
AT+PER?  → AT+PER=60,600 + OK
```

## 2.2 硬件层（door / io / pwr）

仅带相应硬件的型号支持；其他型号回 `ERR3`。

| key | AT 指令 | value 格式 | 说明 | 状态 | 生效 |
| --- | --- | --- | --- | --- | --- |
| `door` | `AT+DOOR?` | 只读 | 两路门磁状态 `1`=吸合（CN4/PB01、CN3/PC02） | 现行 | 即时 |
| `io` | `AT+IO=` | `0/1` | CN2 输出，高有效 | 现行 | 立即 |
| `pwr` | `AT+PWR=` | `预供电秒,采后保持秒` | 外设/传感器供电；`0,0`=采前上电 ≥15ms、采完即关。**采集器**（含 **WW-D5-L**）适用；D5L 外供电脚为 **PC09**（高有效，空闲默认关断） | 现行 | 下周期 |

```
AT+DOOR?          → AT+DOOR=1,0 + OK
AT+IO=1
AT+PWR=2,1
AT+PWR=0,0        # 最短上电采完即关
AT+PWR=3,1        # WW-D5-L 示例：预供电 3s，采后保持 1s
```

## 2.3 射频层 · LoRa网络（lora / exlora / ack / batt / aes / eui）

| key | AT 指令 | value 格式 | 说明 | 状态 | 生效 |
| --- | --- | --- | --- | --- | --- |
| `lora` | `AT+LORA=` | `发频点,发SF,收频点,收SF,netid,功率,频宽,编码率` | 8 段位置参数；频点约 400M~510M，SF7~12，功率约 -9~22 dBm | 现行 | 立即 |
| `exlora` | `AT+EXLORA=` | `发极性,收极性,前导,跳频` | 扩展射频 | 现行 | 立即 |
| `ack` | `AT+ACK=` | `0/1` | 客户 ACK | 现行 | 立即 |
| `batt` | `AT+BATT=` | `lo,hi`（mV） | 电量区间 | 现行 | 立即 |
| `aes` | `AT+AES=` | 128-bit 密钥，**16 字节**十六进制（共 **32** 个 hex 字符，无 `0x`、无空格、大小写均可） | **私有 LoRa 空口 AES 密钥**（不是开/关）。写入后按该密钥加解密载荷；远程「编号+AT」前缀仍为明文，**不建议**远程开放改 `aes` | 建议项（`ATH` 列出则计入） | 立即 |
| `eui` | `AT+EUI=`（`ATH` 若写 `AT+DEVEUI` 同义） | 16 位十六进制，无空格、大小写均可 | **LoRaWAN DevEUI**，固定 **8 字节**；组成见下方备注 | LoRaWAN / HW 族 | 立即 |

空字段 = 不改该项（位置参数，仅 `lora`/`exlora`）。

```
AT+LORA=470300000,7,470300000,7,1,14,0,1
AT+EXLORA=0,0,8,0
AT+ACK=1
AT+BATT=2800,3600
AT+AES=00112233445566778899AABBCCDDEEFF
AT+EUI=70B3D57ED0001234
AT+LORA?
AT+EXLORA?
AT+BATT?
AT+AES?
AT+EUI?
```

### 2.3.1 备注：设备编号 / DevEUI / AES

| 项 | 口径 |
| --- | --- |
| **私有 LoRa 设备编号** | **4 字节**（大端无符号整数）。串口 / 空口文本常写成 **8 位十六进制**，如 `00000135`、`12345678`；二进制帧 DevAddr 同为 4 字节。与 `AT+INFO?` 的编号字段对应。 |
| **LoRaWAN DevEUI** | **8 字节**（16 位十六进制）。**DevEUI = 前缀（4 字节）+ 标号（4 字节）**：前缀由产线/运营商分配；标号与私有侧 4 字节设备编号同一数值（即 DevEUI 的后 4 字节 = 设备编号）。例：前缀 `70B3D57E`、标号 `D0001234` → DevEUI `70B3D57ED0001234`，私有编号仍按 4 字节 `D0001234`（文本 `D0001234`）寻址。 |
| **配置入口** | 写/读 DevEUI：`AT+EUI=` / `AT+EUI?`（固件清单若为 `AT+DEVEUI`，按 `ATH` 实名）。改 DevEUI 后需与入网平台档案一致，否则 OTAA 失败。 |
| **AES** | 私有空口用 `AT+AES=` 写入 **128-bit（16 字节）密钥**，值是 32 个 hex 字符，例如 `AT+AES=00112233445566778899AABBCCDDEEFF`。**不是** `0/1` 开关。LoRaWAN 入网密钥（AppKey 等）走模组/LoRaWAN 栈，与本 key 不同；二者勿混。远程下发白名单建议排除 `aes`/`eui`/`ver`。 |
| **条数** | `aes`/`eui` 为建议/族相关项：**不计入** §3.0.1 射频固定 4 条（`LORA`/`EXLORA`/`ACK`/`BATT`）；`ATH` 列出则以实机为准，产线对账时核对。 |

> 平台建档：私有网关按 **4 字节编号**；LoRaWAN 网络服务器按 **8 字节 DevEUI**，并用同一标号关联两套档案。

## 2.4 系统层（ver / log）与监听

| key | AT 指令 | 值 | 说明 | 状态 | 生效 |
| --- | --- | --- | --- | --- | --- |
| `ver` | `AT+VER=` | `型号,产品版本` | 与上报 model 同源；现场勿乱改型号串 | 现行 | 重启 |
| `log` | `AT+LOG=` | `0/1` | 串口调试日志 | 现行 | 立即 |
| `lis` | `AT+LIS=` | `1~30` 秒，`0`=关 | 上报后监听下行配置的时间窗（默认 3） | 现行 | 立即 |

> 规范系统层仅 `ver`/`log`。`lis` 为远程窗口配套（与合并手册一致），便于空口收配置。

```
AT+VER=WW10L,1.0.0
AT+LOG=0
AT+LIS=3
```

## 2.5 控制与查询（非 key）

| 指令 | 形态 | 说明 |
| --- | --- | --- |

## 3.4 其他 L 族（压力 / 运动 / 采集器 / 控制）

- **压力 / 液位 / 拉力（模拟量）**：**支持** `unit` / `ran`（与 4G 同枚举与段序）。  
  - `AT+UNIT=`：`0` Pa / `1` kPa / `2` MPa / `3` bar / `4` cm / `5` m  
  - `AT+RAN=`：`起始,满量程`，单位随 `unit`  
  - **量产场景**：同款 0–3V ADC 前端，SKU 量程不同（如 1 / 2 / 3 MPa）时，用 `AT+RAN=`（+ `AT+UNIT=`）把 ADC 满量程映射到工程量程；例 `AT+UNIT=2` + `AT+RAN=0,3` → 0~3 MPa。  
  - 旧压力机若仍保留私有寄存器量程项，可作补充通道；**以 `ATH` 列出的 `UNIT`/`RAN` 为准**，勿与「不支持 unit/ran」旧说法并用。  
```
AT+UNIT=2
AT+RAN=0,3
AT+UNIT?
AT+RAN?
```
- **运动类**：`acc` 预留（ERR3）。  
- **采集器**：`pwr` 属硬件层；**WW-D5-L RS485/Modbus 采集**见 **§3.5**（D1L/D2L/D3L 若 ATH 列 MB* 亦同口径）。  
- **控制类**：`io`（及固件若实现的 `omd`/`pls`）以 `ATH` 为准。


## 3.5 WW-D5-L（RS485 Modbus 采集）

权威来源：官网产品 AT 页 **WW-D5-L / FW 1.5.0**（`protocol-at-command-new.html`）。功能定位：**RS485 Modbus 采集 → LoRa 私有网 TLV 转发**（无 4G、无 JSON 空口）。

### 3.5.1 能力集与 ERR3

| **WW-D5-L** 上的 `unit`/`ran`/`var`/`zero`/`thre`/`rst`/`server`/`mqtt`/`mbpoll` | 非本机能力集（产品页） | `ERR3` |
| 非 D5L（或 ATH 未列）的 `mbuart`/`mbmode`/`mbcmd`/`mbscan`/`mbraw` | 能力集外 | `ERR3` |

平台下发前先跑 `ATH`，清单外不下发。

# 第三部分 · 远程配置

同一张 key 表；**私有 LoRa 远程配置**明确支持两种下行格式（可在同一监听窗口内并用）。设备先判是否「8 位设备编号 + AT 文本」；对上则按**远程 AT**执行，否则再按 **Modbus 寄存器帧**解析。

| 载体 | 场景 | 格式 |
| --- | --- | --- |
| **本地 AT** | 产测 / 现场串口 / BLE | `AT+KEY=value`（本文表） |
| **远程 AT（无线 AT）** | 私有空口 / 网关透传 | `设备编号` + `AT` 指令，无空格，见 **§5.2** |
| **Modbus 配置** | 私有空口 / 网关透传 | 设备编号 + 功能码 `10`/`03` + 寄存器 + 数据 + CRC16，见 **§5.3** |
| **LoRaWAN 下行** | 设备已入网（LoRaWAN） | Type `0x01`+`0x81` 读；Type `0x02`+功能码写，见 **§5.4** |

> **要点**：远程配置 ≠ 仅 LoRaWAN。私有网上行上报走 TLV（§6）；**下行改参**走 **远程 AT** 或 **Modbus**。

## 5.1 本地 AT

同第一部分；上报后可用 `AT+LIS` 留监听窗收后续下行（远程 AT 或 Modbus）。

## 5.2 远程 AT（设备编号 + AT）

载荷为 **ASCII 文本**（无 CRC），长度即 LoRa 包长；末尾 `\r`/`\n` 可有可无。

```text
<8位十六进制设备编号><AT指令>
```

| 规则 | 说明 |
| --- | --- |
| 设备编号 | 与 `AT+INFO?` 的 `NO` 相同，**4 字节**常写成 **8 位 hex**（如 `12345678`、`00000135`），大小写均可；与 `AT` 之间**无空格、不带型号** |
| 寻址 | 设备只处理编号匹配的帧；不匹配**不应答**（防同频广播） |
| 广播 | 编号 `FFFFFFFF` + **写指令**（含 `=`、不含 `?`）时，在听设备都执行且**不回包**；查询 / `AT+REPORT` / `ATR` 丢弃；**禁止广播 `AT+MBRAW`**（WW-D5-L） |
| 单播应答 | 把串口会打印的应答原样接在 **8 位大写编号**后发回；查询常为两段（`AT+KEY=…` 再 `OK`），中间 `\r\n`，同一空口包 |
| 可用指令 | 与串口命令态同能力集（见第一部分）；`aes`/`eui`/`ver` 不建议远程开放 |
| 与 LoRaWAN | **不用**本帧寻址 DevEUI；LoRaWAN 入网后走 §5.4 |

**改周期示例**（设备 `12345678`，检测 30 s / 发送 60 s）：

```text
12345678AT+PER=30,60
```

其它示例：

```text
12345678AT+PER?
00000135AT+LORA=,10
00000135AT+IO=1
FFFFFFFFAT+PER=60,600
```

单播成功应答示意：`12345678OK`（查询则先回显再 `OK`）。

## 5.3 Modbus 配置（设备编号 + 写/读寄存器）

二进制，**大端**。CRC-16/**XMODEM**（多项式 `0x1021`，初值 `0`，XorOut `0`），覆盖 CRC 之前全部字节，与上行 TLV 同一套。设备地址 = 设备号 4 字节数值（`12345678` → `12 34 56 78`）；广播地址 `FF FF FF FF`。

### 5.3.1 写多个寄存器（功能码 `0x10`）

```text
DevAddr(4) | 10 | 起始寄存器(2) | 寄存器个数(2) | 字节数(1) | 数据(个数×2) | CRC16(2)
```

字节数必须 = 寄存器个数 × 2。单播写成功回 11 字节：`DevAddr(4) | 10 | 起始(2) | 个数(2) | CRC16(2)`；广播写成功不回包。

**改 `per` 示例**（设备 `12345678`，`PER` 占用寄存器 **`0x0001`～`0x0002`** 共 2 个；写成检测 **0**、发送 **10** → 数据 `0000 000A`）：

```text
12 34 56 78 10 00 01 00 02 04 00 00 00 0A 86 3F
```

对照拆解：

| 字段 | hex | 含义 |
| --- | --- | --- |
| 设备编号 | `12 34 56 78` | `12345678` |
| 功能码 | `10` | 写多个寄存器 |
| 起始 | `00 01` | 寄存器 `0x0001` |
| 个数 | `00 02` | 2 个寄存器（`0001`～`0002`） |
| 字节数 | `04` | 4 字节数据 |
| 数据 | `00 00 00 0A` | 检测=0，发送=10（各 **uint16**） |
| CRC | `86 3F` | XMODEM，初值 0 |

紧凑写法（与口头「设备编号 + 10 + …」一致，空格可省）：

```text
123456781000010002040000000A863F
```

> 平台/工具若另算 CRC，须与设备同算法（XMODEM init=0）；上表 CRC 按该算法现算。若工具给出其它 CRC（如 `7267`），先核对字节序与初值是否一致。

### 5.3.2 读保持寄存器（功能码 `0x03`）

仅单播，个数 1～32：

```text
DevAddr(4) | 03 | 起始(2) | 个数(2) | CRC16(2)
```

应答：`DevAddr(4) | 03 | 字节数(1) | 数据 | CRC16(2)`。

### 5.3.3 key ↔ 寄存器（**连续编号**；写入须按组一次写齐）

> **规则**：配置区 **`0001`～`000A` 按序排满、中间不留空号**；射频从 **`0010`** 起按序排满、中间不留空号。旧地址（如 `0005`/`000F`/`0015`/`00F0`/`0100`…）作废，以本表为准。

#### 配置区 `0001`～`000A`（连续）

| 地址 | 对应 AT / 项 | 编码 |
| --- | --- | --- |
| `0001` | `AT+PER` 检测秒 | uint16 |
| `0002` | `AT+PER` 发送秒 | uint16 |
| `0003` | `AT+VAR` 温度变化量 | int16，0.01℃ |
| `0004` | `AT+VAR` 湿度变化量 | int16，0.01%RH |
| `0005` | `AT+CAL` 温度校准 | int16（对齐产品；无该能力则忽略/ERR） |
| `0006` | `AT+CAL` 湿度校准 | int16 |
| `0007` | `AT+LOG` | uint16，`0`/`1` |
| `0008` | `AT+ACK` | uint16，`0`/`1` |
| `0009` | `AT+BATT` 下限 | uint16，单位 **0.1 V** |
| `000A` | `AT+BATT` 上限 | uint16，单位 **0.1 V** |

写 `per` 仍为起始 `0001`、个数 `2`（见 §5.3.1 示例）。写 `var`：起始 `0003`、个数 `2`；写 `batt`：起始 `0009`、个数 `2`。

#### 衔接区 `000B`～`000F`（连续，紧接配置区）

| 地址 | 项 | 编码 |
| --- | --- | --- |
| `000B` | 控制 | `0x0001` 立即上报；`0x0002` 重启（广播拒绝） |
| `000C` | `AT+UNIT`（模拟量机） | uint16，单位枚举（无则保留） |
| `000D` | `AT+RAN` 起始 | int16 / 按产品 |
| `000E` | `AT+RAN` 满量程 | int16 / 按产品 |
| `000F` | 保留 | 写 0；占位保持连续 |

门磁/水浸等无 `VAR`/`CAL`/`ZERO`/`UNIT`/`RAN` 的型号：对应寄存器**可不实现**或写无效；以 `ATH` 为准。

#### 射频区从 `0010` 起（连续，对应 `AT+LORA` / `EXLORA`）

32 位字段须**高低两个寄存器同一次写入**。

| 地址 | 字段 | 广播 |
| --- | --- | --- |
| `0010` | 网络号 net_id | 拒绝 |
| `0011` | 发送 SF | 允许 |
| `0012` | 接收 SF | 允许 |
| `0013`～`0014` | 发送频点 Hz，uint32 | 允许 |
| `0015`～`0016` | 跳频步进 Hz，uint32 | 允许 |
| `0017` | 信道个数 | 允许 |
| `0018` | 跳频开关 0/1 | 允许 |
| `0019`～`001A` | 接收频点 Hz，uint32 | 允许 |
| `001B` | 发送极性 iq_tx | 拒绝 |
| `001C` | 接收极性 iq_rx | 拒绝 |
| `001D` | 前导长度 | 允许 |
| `001E` | 编码率 1～4 | 允许 |
| `001F` | 发射功率 dBm，int16 | 拒绝 |
| `0020`～`0021` | 带宽 Hz，uint32 | 允许 |
| `0022` | 接收轮询毫秒 | 允许 |

#### 只读区从 `0023` 起（连续，紧接射频）

| 地址 | 含义 |
| --- | --- |
| `0023`～`0024` | 固件标识（固定示意值以产品为准） |
| `0025` | 电量格 |
| `0026` | 射频是否就绪 |
| `0027`～`0028` | 最近压力缓存（0.01 kPa；无则 0） |
| `0029` | 最近温度 0.01℃ |
| `002A` | 保留 / 0 |

`AT+IO` / `AT+PWR` / `AT+DOOR?` / `AT+INFO?` **仅**远程 AT 文本通路有，寄存器帧无对应项。

## 5.4 LoRaWAN 下行 · key ↔ 功能码

| key | 写功能码 | 载荷 | 说明 |
| --- | --- | --- | --- |
| `per`（上报段） | `0x11` | uint16，秒 | LFT |
| `per`（检测段） | `0x12` | uint16，秒 | LCP |
| `cal` | `0x13` | 4 字节 | 字节1 温度 0.1℃、字节2 湿度 1%RH、后 2 字节填 0 |
| `var`（温度） | `0x14` | uint8 | 温度变化量 |
| `var`（湿度） | `0x15` | uint8 | 湿度变化量 |
| `tun` | `0x17` | uint8 | 温标 0=℃ / 1=℉ |

读：Type `0x01` + Value `0x81` → 回 `0x81` + Length + 按序 value（Length 自适应，只回已实现项）。

对时：下行 `0x02`+`0x00`+`YYMMDDhhmmss`（无 4G 的 JSON `tt`）。

## 5.5 监听窗口 `lis`

每次上报后保持接收 `lis` 秒（默认 3；部分产品开机窗更长）。`0`=不留窗。取值 1~30。远程 AT 与 Modbus 均在此窗口内下发。

### 6.1 空口 TLV 帧结构

来源：官网 TLV-V1（至 V1.7.2）。编码：**大端（BE）**；**无 SOF**。

```text
Header(1) | DevAddr(4 BE) | FCtrl(1) | SeqNo(2 BE) | Data1…DataN (TLV…) | CRC(2 BE)
```

| 偏移 | 长度 | 字段 | 解析 |
|------|------|------|------|
| 0 | 1 | **Header** | **协议版本号**（整字节），**无 MType**。当前常用 **`0x03`**；部分现网产品（如 WW-27L）写作 **`0x10`**，见 §6.4 |
| 1 | 4 | **DevAddr** | 设备 ADDR，大端；对应 `AT+ADDR?` / 私有编号 4 字节 |
| 5 | 1 | **FCtrl** | **私有协议** = 事件字段（见 §6.1.2）；**LoRaWAN** 则按 LoRaWAN 规范的 FCtrl，勿与私有混用 |
| 6 | 2 | **SeqNo** | 主动上报时序号自增（注册包通常不递增） |
| 8 | N | **Message Body** | 若干 TLV；部分类型省略 Length，见 §6.2 |
| 8+N | 2 | **CRC** | 公司自定义 CRC16，覆盖 Header…Body；见 §6.5 |

要点：Body 为「类似 TLV」——基础类型多为 **T+V（省略 Length）**；`0x10+` 为 **T+L+V**。无整帧 PayloadLen；解析靠 Type 表直到只剩末尾 2 字节 CRC。

#### 6.1.1 Header（版本号）

**Header 就是版本号**，整字节表示协议版本，**不拆 MType**。

| Header | 含义 |
|--------|------|
| `0x03` | 当前文档主口径版本（与多数 TLV-V1 材料一致） |
| `0x10` | 部分现网私有实现（如 WW-27L）首字节，见 §6.4 |

> 旧材料若写「高 3 bit = MType、低 5 bit = Version」——**作废**；以本节为准：Header = 版本号。

#### 6.1.2 FCtrl

分两种链路，**不可混解析**：

| 链路 | FCtrl 含义 |
|------|------------|
| **LoRaWAN** | 按 **LoRaWAN 协议** 的 FCtrl（ADR / ACK / FOptsLen 等），本文不改写规范位域 |
| **私有协议** | **事件字段**（下表）；与 LoRaWAN FCtrl **不是同一套位义** |

**私有协议 FCtrl 位域**

| 位 | 名称 | 含义 |
|----|------|------|
| **7** | **ACK** | `1` = 请求下行应答（与 `AT+ACK=1` 相关）；`0` = 不请求 |
| **6:0** | **事件 Event** | 事件类型，取值见 **§6.1.3**（0～127） |

整字节示意：`FCtrl = (ACK << 7) | Event`。例如事件=注册 `10`、未开 ACK → `0x0A`；开 ACK → `0x8A`。

#### 6.1.3 事件类型（私有协议 Event，FCtrl bit6:0）

| 值（十进制） | hex | 名称 | 说明 |
|-------------|-----|------|------|
| **0** | `0x00` | **状态** | 周期/心跳等到点上报（状态包） |
| **1** | `0x01` | **值变化** | 测量值超变、开关量边沿等 |
| **2** | `0x02` | **按键** | 短按松手，或 `AT+REPORT` |
| **3** | `0x03` | **预警** | 阈值/预警类（产品实现则发） |
| **4** | `0x04` | **关机** | 主动下线/进休眠前最后一包（若产品有） |
| **5** | `0x05` | **开机** | 从关机态唤醒后的开机包（**不是**注册） |
| **6** | `0x06` | **补传** | 补发/重传类（若产品有） |
| **7** | `0x07` | **应答** | 对下行的业务应答类（若产品有；区别于 Type `0xFF`） |
| **8** | `0x08` | **配置回执** | 远程配置结果回执（若产品有） |
| **10** | `0x0A` | **注册** | 上电/入网后的注册包 |

> 平台旧 JSON `evt` 与上表同口径时：`0` 状态、`1` 变化、`2` 按键、`10` 注册。未列出的取值保留，**勿自造**与产品不符的事件码。  
> 部分旧固件（WW-27L）曾用「低 4 位事件 + TRIG/ACK 高位」另一套打包，见 **§6.4**；**新口径以本节 bit7=ACK、bit6:0=事件为准**。

### 6.2 Type 范围与总表

#### 6.2.1 Length 模式

| Type 范围 | Length 模式 | 说明 |
|-----------|-------------|------|
| **`0x00`~`0x0F`** 与 **`0xFF`** | **T+V**（省略 Length） | 基础传感器类型，值长度由 Type 表固定 |
| **`0x10`~`0x1F`** | **T+L+V** | 通用类型 |
| **`0x20`~`0x7F`** | **T+L+V** | 定制化项目 |
| **`0x80`~** | **T+L+V** | 用户参数配置查询 |

解析：读 Type → T+V 查定长前进；T+L+V 再读 1 字节 Length 再读 Value。未知 Type：T+V 区间**无法安全跳过**（须字典同步）；T+L+V 可按 Length 跳过。

#### 6.2.2 基础传感器类型（T+V）

| Type | 名称 | Value 长度 | 编码 | 单位 / 语义 |
|------|------|------------|------|-------------|
| `0xFF` | 应答 ACK | 2 | 第 1 字节=对应下行指令类型；第 2 字节=结果 | 上行应答 |
| `0x00` | 设备信息 | 2 | 位域，见 §6.3.1 | 版本 / 电压档 / 异常 / devType |
| `0x01` | 加速度 | 8 | Event(1) + X/Y/Z 各 int16 + Reserve(1) | 震动/撞击 |
| `0x02` | 地理坐标 | 8 | 经度 float32 + 纬度 float32 | 按项目 |
| `0x03` | 采样数据 | 2 | uint16 | 项目定制 |
| `0x04` | 温度 | 2 | int16 | **默认 0.1 ℃** |
| `0x05` | 湿度 | 1 | uint8 | **1 %RH** |
| `0x06` | 含量 | 1 | uint8 | 百分比，项目定制 |
| `0x07` | 压/拉力 | 4 | int32 | 默认 Pa；拉力为 N |
| `0x08` | 传感值 | 4 | float32 | 项目定制 |
| `0x09` | 开关量 | 1 | bit 图，最多 8 路 | 阀门/水浸/烟感等 |

> ⚠ WW-27L 另有 **`0x0D` IO（1B）**（官网基础表未收录）；且 `00/04/05/09` 编码见 §6.4。

#### 6.2.3 定制化类型（T+L+V）

| Type | 名称 | Length 约定 | Value 描述 |
|------|------|-------------|------------|
| `0x10` | 通信参数 | N | TFREQ(u32)+LCP(u16)+RPREM(u16)+LFT(u16)+TSF(u8) |
| `0x11` | 多轴倾角 | N×4 | 每轴 int32，**0.001°**；N=1/2/3 → X / XY / XYZ |
| `0x12` | 多路温湿度 | N×4 | 每路：温度 int16 + 湿度 uint16，分辨率 **0.1** |
| `0x13` | 多路采样 | N×2 | N 组 uint16 |
| `0x14` | 多路温度 | N×2 | N 组 int16 |
| `0x15` | 多路湿度 | N | N 组 uint8 |
| `0x17` | 多路压/拉力 | N×4 | N 组压/拉力 |
| `0x18` | 多路传感值 | N×4 | N 组传感数据 |
| `0x1A` | 电流电压 | 2 或 4 | L=2：仅电流 mA；L=4：电流 + 电压（**0.1 V**） |
| `0x1B` | 功率电能 | 4（常见） | 有功功率 P，单位 **W** |
| `0x20` | 仪表地址 | N | 从机/仪表地址（表计常见 7/14） |
| `0x21` | 业务数据 | N | 外接原始；部分项目首字节区分业务 |
| `0x22` | 阀门响应 | N | 项目定制 |
| `0x24` | Modbus 数据 | N | 从机主动上报的 Modbus 内容 |
| `0x25` | 用户命令数据 | N | 前 1 字节命令序号（从 0）+ 用户内容 |
| `0x30` | 混合气体 | 常 5 | 气体类型(1) + int32（分辨率 **0.01**） |
| `0x38` | 带单位传感值 | **5** | 单位类型(1) + float32(4) |
| `0x40` | 存储记录 | 常 12 | RecordID(u32)+YYMMDDhhmmss(6)+Status(2) |
| `0x80` | 公共配置 | N | 如 4G：服务器,端口,方式；MQTT 附加用户名等 |
| `0x81` | 用户参数 | N | 上报/检测周期、校准、变量… |

> 官网定制表**无 `0x16` 数据类型**（`0x16` 仅出现在 **devType**=红外温度）。本文**不发明**未在官网列出的 Type 码。

### 6.3 基础 / 定制 Type 详解

#### 6.3.1 `0xFF` 通用应答（上行）

| 字段 | 长度 | 说明 |
|------|------|------|
| Type | 1 | `0xFF` |
| 响应命令类型 | 1 | 对应下行指令 Type |
| 响应结果 | 1 | 按项目约定 |

#### 6.3.2 `0x00` 设备信息

| 字节 | 位域 |
|------|------|

**devType 表（官网）**

| `0x08` | 压力（带单位） | `0x25` | 灯带（16 路） |
| `0x09` | 控制器（功率） | `0x34` | CO2 |
| `0x0A` | 位移 | `0x36` | O2 |
| `0x0B` | 测距 | `0x50` | 震动 |
| `0x0C` | 多路控制器 | `0x51` | 倾角 |
| `0x10` | 温湿度 | `0x52` | 震动倾角 |
| `0x11` | 温度 | `0x70` | 大气压 |
| `0x13` | 红外温度水浸 | `0x71` | 水位 |
| | | `0x72` | 拉力 |

#### 6.3.3 `0x01` 加速度计

Event(1)：`0x00` 正常 / `0x01` 震动 / `0x04` 撞击；随后 X/Y/Z 各 int16 BE；Reserve(1)。

#### 6.3.4 `0x02` / `0x03` / `0x06` / `0x07` / `0x08`

- **`0x02` 地理坐标**：经度 float32 + 纬度 float32。  
- **`0x03` 采样**：uint16，项目定制。  
- **`0x06` 含量**：uint8 %。  
- **`0x07` 压/拉力**：int32；压力默认 Pa，拉力 N。  
- **`0x08` 传感值**：float32，项目定制。

#### 6.3.5 `0x04` 温度 / `0x05` 湿度

- **温度**：int16，官网默认 **0.1 ℃**（201 → 20.1℃）。  
- **湿度**：uint8，**1 字节**，单位 **1 %RH**。  
- ⚠ WW-27L 为 0.01 ℃ / 2B·0.01 %RH，见 §6.4。

#### 6.3.6 `0x09` 通用开关量

最多 8 路，一般 **1 bit = 1 路**。阀门：`0x01` 开 / `0x00` 关；水浸：`0x01` 有水 / `0x00` 无水。

**烟雾报警器 bit 图（官网）**

| bit | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|-----|---|---|---|---|---|---|---|---|
| 含义 | 开机 | 激活 | 拆除 | 保留 | 测试 | 电量 | 故障 | 报警 |
| 0 / 1 | 正常/开机 | 正常/激活 | 正常/拆除 | 默认 | 正常/测试 | 正常/低电 | 正常/故障 | 正常/报警 |

#### 6.3.7 定制 Type 摘要（`0x10`～`0x81`）

| Type | 要点 |
|------|------|
| `0x10` | 旧版 LoRa 配置回读：TFREQ→LCP→RPREM→LFT→TSF |
| `0x11` | 倾角：每轴 int32，**0.001°**；Length/4 = 轴数 |
| `0x12` | 多路温湿度：每路 int16 温 + uint16 湿，**0.1** |
| `0x13`/`0x14`/`0x15` | 多路采样 / 温度 / 湿度 |
| `0x17`/`0x18` | 多路压拉力 / 多路传感值 |
| `0x1A` | L=2 仅电流 mA；L=4 电流 + 电压 0.1 V |
| `0x1B` | 有功功率 W（常见 L=4） |
| `0x20` | 仪表地址 |
| `0x21` | 业务数据；首字节可区分：`00` 灯控 / `01` 网关电能 / `02` 热表 / `03` 特殊气体 / `04` 接地环流 / `05` 测控仪表 |
| `0x22` | 阀门响应（项目定制） |
| `0x24` | Modbus 从机上报内容 |
| `0x25` | 命令序号(1) + 用户内容 |
| `0x30` | 气体类型(1)+int32(0.01)：`01` CH4 / `02` CO / `03` H2S / `04` CO2 / `05` NH3 |
| `0x38` | 单位码(1)+float32；单位：0 Pa · 1 hPa · 2 kPa · 3 MPa(默认) · 4 PSI · 5 PSF · 6 kg/cm² · 7 mH2O · 8 mmH2O · 9 bar · 10 mbar · 11 mmHg · 12 inHg · 13 atm |

| `0x80` | 公共配置字符串（4G/MQTT 等） |
| `0x81` | 顺序：上报周期 u16、检测周期 u16、校准 int32、变量 1~3 u8；用 Length 裁剪 |

### 6.4 WW-27L 产品实现差异

| 维度 | 官网 TLV-V1 | WW-27L 产品手册 |
|------|-------------|-----------------|
| 首字节 / Header | **版本号**整字节 **`0x03`**（无 MType） | 固定写作 **`0x10`（版本）** |
| 控制字 | **私有 FCtrl**：bit7=ACK，bit6:0=事件（§6.1.2～6.1.3） | **旧实现**：低 4 位事件 + TRIG/ACK 高位（与新口径不同） |
| Type `0x00` | 设备信息位域 | **HB**：电量% + 类型码 **27** |
| Type `0x04` | **0.1 ℃** | **0.01 ℃** |
| Type `0x05` | **1 字节 / 1 %RH** | **2 字节 / 0.01 %RH** |
| Type `0x09` | 通用开关 / 烟感 bit 图 | **DOOR** bit0/bit1，**1=吸合** |
| Type `0x0D` | **未列出** | **IO**（CN2 输出 0/1） |
| CRC | 自定义，**init=`0xFFFF`** | 材料称 **XMODEM**，**init=`0`** |

**WW-27L Type 子集与拼接顺序**：`HB(00)` →（可选）`TEMP(04)` →（可选）`HUMI(05)` → `DOOR(09)` → `IO(0D)`。SHT40 失败则省略 TEMP/HUMI。

**WW-27L 旧「计时事件」打包（低 4 位事件；与 §6.1.3 新口径不同，仅对照现网）**

| 低 4 位 | 名称 | 含义 |
|---------|------|------|
| `0x0` | 心跳 | `AT+PER` 周期到 |
| `0x1` | 检测 | 门磁边沿 / 超 `AT+VAR` |
| `0x2` | 按键 | 短按或 `AT+REPORT` |
| `0x3` | 预警 | 本产品保留 |
| `0x4` | 关机 | 长按满 5 秒休眠前 |
| `0x5` | 开机 | 关机态长按满 5 秒（**非**注册） |
| `0xA` | 注册 | 上电首包，同时 TRIG=1 |

常见整字节（旧打包）：`0x1A` 注册；`0x04`/`0x24` 关机；`0x05`/`0x25` 开机。**新口径**对应：注册=`0x0A`/`0x8A`，状态=`0x00`/`0x80`，值变化=`0x01`/`0x81`，按键=`0x02`/`0x82`（高字节位为 ACK），见 **§6.1.3**；迁移对照 **§6.6.2**、**§6.6.5**。

**WW-27L 示例 hex**（DevAddr=`12345678`，Seq=42，电量 85%/类型 27，27.00℃，55.00%RH，门磁 bit0=1，IO=0；CRC 按 XMODEM init=0）：

心跳：

```text
10 12 34 56 78 00 00 2A 00 55 1B 04 0A 8C 05 15 7C 09 01 0D 00 03 02
```

注册（`0x1A`，Seq=1 示意；注册包 Seq **不递增**）：

```text
10 12 34 56 78 1A 00 01 00 55 1B 04 0A 8C 05 15 7C 09 01 0D 00 8A E3
```

> **不可**与官网默认精度（温度 `01 0E`=27.0×10、湿度 1B `37`、Header=`0x03`、CRC init FFFF）混用同一解析器。

### 6.5 CRC

| 项 | 官网 TLV-V1 | WW-27L 材料 |
|----|-------------|-------------|
| 算法 | 公司自定义（官网附录） | 称 **CRC-16/XMODEM** |
| 初值 | **`0xFFFF`** | **`0`** |
| 覆盖 | Header…Body（CRC 前全部字节） | 同左 |
| 字节序 | 大端 2 字节帧尾 | 大端 |

⚠ 初值不同 → 同一明文 CRC **不同**；产品须标明走哪套。WW-27L 仍为 init=`0`，**不可**与下表官网参考代码混用。

官网附录参考代码（TLV-V1 V1.7.2；init=`0xFFFF`）：

**C**

```c
static uint16_t get_crc16(uint16_t inData, uint16_t outData) {
  outData = (outData >> 8) | (outData << 8);
  outData ^= inData;
  outData ^= (outData & 0xff) >> 4;
  outData ^= outData << 12;
  outData ^= (outData & 0xff) << 5;
  return outData;
}

static uint16_t cal_crc16(const uint8_t *pData, const uint32_t len) {
  uint32_t i = 0;
  uint16_t crc16 = 0xFFFF;
  for (i = 0; i < len; i++) {
    crc16 = get_crc16(*(pData++), crc16);
  }
  return crc16;
}
```

**Java**

```java
public static int calcRJCRC16(byte[] bytes) {
    int crc = 0xffff;
    for (byte seed : bytes) {
        crc = (crc >>> 8) | (crc << 8);
        crc ^= seed & 0xff;
        crc ^= (crc & 0xff) >> 4;
        crc ^= crc << 12;
        crc ^= (crc & 0xff) << 5;
        crc = crc & 0xffff;
    }
    return crc;
}
```

### 6.6 报文设计（注册包 / 数据包）

> **规范建议**（新固件 / 新对接以本节为准）。现网 **WW-27L** 仍可能只发测量子集、无配置快照 Type，见 §6.4；产品迁移时按矩阵补齐。

公共帧外形（同 §6.1）：

```text
Header | DevAddr(4) | FCtrl(1) | SeqNo(2) | TLV… | CRC(2)
```

#### 6.6.1 注册包（入网 / 上电首包）

**用途**：标识设备 + 基线配置快照 +（建议）本型测量快照，便于平台建档。

| 项 | 规范建议 | 说明 |
|----|----------|------|
| Header | **版本号** `0x03`（无 MType） | WW-27L 现网写作 `0x10`，见 §6.4 |
| FCtrl | **私有**：事件=`10` 注册 → `0x0A`（ACK=0）或 `0x8A`（ACK=1） | WW-27L 旧打包常见 **`0x1A`**（TRIG+事件 `0xA`），见 §6.4 |
| SeqNo | **不递增**（可用固定值，如 `0001`） | 与 WW-27L 产品约定一致；其余包再自增 |
| Body 顺序（建议） | ① `0x00` → ② 配置 Type → ③ 本型测量 Type | 见下 |

**Body 组成**

1. **必选** `0x00` 设备信息（官网位域：Version / 电压档 / 异常 / **devType**）。  
2. **建议配置快照**（只用已有 Type，语义对齐 AT）：  
   - **`0x81` 用户参数**（T+L+V）：周期 / 校准 / 变量  
   - **`0x10` 通信参数**（T+L+V）：私有 LoRa 射频关键段（旧版回读布局）  
3. **建议** 本型测量 Type（与 §6.6.2 / §6.6.3 相同子集，便于首包即有状态）。

**`0x81` 用户参数 ↔ AT 对照**

| `0x81` Value 顺序 | 类型 | 对应 AT | 备注 |
|-------------------|------|---------|------|
| 1. 上报周期 | uint16 BE | `AT+PER=` 的**发送秒**（第 2 段） | |
| 2. 检测周期 | uint16 BE | `AT+PER=` 的**检测秒**（第 1 段） | 与 AT 字符串段序**相反** |
| 3. 校准值 | int32 BE | `AT+CAL=`（单值/首路；多路产品另议） | Length 不够则省略 |
| 4~6. 变量 1~3 | uint8 | `AT+VAR=` 相关（按产品裁剪） | 用 Length 裁剪 |

例：`AT+PER=60,600` → Value 前 4 字节 = `02 58 00 3C`（上报 600、检测 60）；Length=`0x04` 时仅两周期。

**`0x10` 通信参数 ↔ AT 对照（私有 LoRa 关键段）**

官网 Value 顺序（用 Length 自适应，满长 11 字节）：

| 顺序 | 字段 | 类型 | 建议对照 | 说明 |
|------|------|------|----------|------|
| 1 | TFREQ | uint32 BE | `AT+LORA` **发频点**（Hz） | 例 `470300000` → `1C 07 F7 B0` |
| 2 | LCP | uint16 BE | 遗留字段；建议填 **发 SF** 或产品定义常量 | 非完整 8 段 `lora` 串 |
| 3 | RPREM | uint16 BE | `AT+EXLORA` **前导** | 例前导 8 → `00 08` |
| 4 | LFT | uint16 BE | 遗留 / 产品定义（可 `00 00`） | |
| 5 | TSF | uint8 | 建议 **发 SF** | 与 `AT+LORA` 发 SF 同值 |

> `0x10` **不能**一次装下完整 `lora` 8 段 + `exlora` 4 段。完整射频仍以 AT / 寄存器 / 下行 Write 为准；注册包 `0x10` 仅作**关键快照**。`batt`/`ack`/`aes`/`eui` **无**对应上行 Type（勿发明）；需查配置走下行 Read（§6.7）或 AT。

**WW-27L 现网**：注册包多为测量子集（`00` HB + 可选温湿度 + `09` + `0D`），**未必**带 `0x81`/`0x10`；新规范建议补齐配置快照。

#### 6.6.2 数据包（周期 / 变化 / 按键等）

| 项 | 规范建议 | 说明 |
|----|----------|------|
| Header | `0x03` | 同注册 |
| FCtrl | **状态** Event=`0`；**值变化** Event=`1`；ACK=bit7 随 `AT+ACK` | 见 §6.1.3 |
| SeqNo | 主动上报**自增** | 注册包除外 |
| Body | **必选** `0x00` + **本型测量 Type** | 一般**不带**配置快照（`0x81`/`0x10`） |

**私有事件 vs WW-27L 旧打包（产品附录）**

| 场景 | 私有 FCtrl（新口径，ACK=0） | WW-27L 旧计时事件整字节（现网） |
|------|--------------------|------------------------------|
| 周期 / 心跳 | Trigger=0（如 `0x00`） | 低 4 位 `0x0`（如 `0x00`） |
| 变化 / 检测 | Trigger=1（如 `0x10`） | 低 4 位 `0x1` |
| 按键 / 手动 | Trigger=1 | 低 4 位 `0x2` |
| 注册 | Trigger=1 | **`0x1A`** |
| 关机 / 开机 | Mark 等（官网仅明确 Mark=`1` 开机） | `0x04`/`0x24`；`0x05`/`0x25` |

测量 Type 失败或传感器异常：该项可整项省略；`0x00` 异常位置 1（官网）。

| **网关/模组** | — | 无测量 Type | — |

> 上报里的门磁/水浸状态走 **`0x09`**；配置侧 `AT+DOOR?` 仍是硬件只读查询，通道不同。

#### 6.6.4 完整示例（官网 TLV-V1 精度基线）

参数约定：DevAddr=`12 34 56 78`；CRC 为官网算法（init=`0xFFFF`，见 §6.5）。温度 **0.1℃**、湿度 **1B·1%RH**（**不是** WW-27L 的 0.01 精度）。

**① 注册包（温湿度 WW-10L 示意）**  
FCtrl=`0x0A`（私有：事件=注册 `10`，ACK=0）；Seq=`00 01`（不递增）；Body：`0x00` 设备信息（电压档示意、devType=`0x10` 温湿度）+ `0x81`（上报 600s / 检测 60s）+ `0x10`（TFREQ=470300000、LCP=7、RPREM=8、LFT=0、TSF=7）+ `0x04`/`0x05`（23.5℃ / 55%RH）。

```text
03 12 34 56 78 10 00 01 00 14 10 81 04 02 58 00 3C 10 0B 1C 07 F7 B0 00 07 00 08 00 00 07 04 00 EB 05 37 A8 91
```

**② 心跳 / 周期数据包（同上测量）**  
FCtrl=`0x00`；Seq=`00 2A`；Body：`0x00` + `0x04` + `0x05`。

```text
03 12 34 56 78 00 00 2A 00 14 10 04 00 EB 05 37 BF 44
```

**③ 门磁变化包**  
FCtrl=`0x01`（私有：事件=值变化 `1`，ACK=0）；Seq=`00 05`；devType=`0x21`；`0x09`=`01`（有状态/打开，按产品极性）。

```text
03 12 34 56 78 10 00 05 00 14 21 09 01 DB A8
```

**WW-27L 现网对照示例**（Header=`0x10`、TEMP/HUMI 为 **0.01** 精度、CRC init=`0`；见 §6.4，**不可**与上列官网示例混用同一解析器）：

```text
心跳：10 12 34 56 78 00 00 2A 00 55 1B 04 0A 8C 05 15 7C 09 01 0D 00 03 02
注册：10 12 34 56 78 1A 00 01 00 55 1B 04 0A 8C 05 15 7C 09 01 0D 00 8A E3
```

### 6.7 下行 Type 紧凑表（官网）

下行帧外形与上行一致。完整寄存器映射仍见 **§5.2 / §5.3**；此处仅列官网 TLV 下行 Type，便于与空口对照。

| Type | 名称 | Value | 说明 |
|------|------|-------|------|
| `0xFF` | ACK | 2B | 第 1 字节备用；第 2 字节：`0` 失败 / `1` 成功 |
| `0x00` | PWR | 1B | `2` = 重启 |
| `0x01` | Read | 1B | `10` 读配置 · `20` 读地址 · `21` 读业务 · `81` 读用户配置 |
| `0x02` | Write | 1+N | 首字节写子类型：时间/地址/频点/扩频/周期/校准/AppKey… |
| `0x21` | Acquire | 1+N | 用户命令透传 |
| `0x22` | Switch | 1B | 开关（`01` 开 / `00` 关） |
| `0x23` | Multiway | 2B | 掩码 + 动作（最多 8 路） |

**Write（`0x02`）子类型摘要**：`00` 时间 YYMMDDhhmmss · `01`/`02` 单播/组播地址 · `03`/`04` 发频点/扩频 · `05` 收前导 · `11`/`12` 上报/检测周期 · `13` 校准 · `14`~`17` 变量 · `40` AppKey(16B) · `41` AppEUI(8B)。

## 7 与 4G 分册差异摘要

| 差异点 | 4G 分册 | 本 LoRa 分册 |
| --- | --- | --- |
| **上报载体** | 设备侧 **JSON** 报文 | 空口 **仅 TLV-V1**（§6）；平台扁平字段由网关翻译（§6.6.5） |
| 网络配置 | `server` / `mqtt` / `apn` / `4G?` | `lora` / `exlora` / `ack` / `batt` |
| 注册快照 | JSON：`per` / `thre` / `server`… | TLV：`0x00` + 建议 `0x81`/`0x10` + 测量 Type（§6.6.1）；**无 `thre`/`server`** |
| 上报蜂窝字段 | `iccid` / `imei` / `csq` | **无**（可选网关附加 RSSI/SNR） |
| 对时 | JSON `tt` | 下行 `0x02+0x00+YYMMDDhhmmss` |
| 阈值 | `thre` 可用 | **预留**（ERR3） |
| 硬件层 | 无 door 配置；io/pwr 按类型 | `door` / `io` / `pwr` |
| 压力/模拟量 | `unit` / `ran` | **支持**（同 4G 枚举；`ran` 用于 ADC→工程量程量产标定） |
| 配置载体 | AT + TCP/UDP/MQTT JSON | AT + **远程 AT** + **Modbus** + LoRaWAN 下行 |
| 电量 | JSON `bat` | TLV `0x00` 电压档（WW-27L：HB 电量%）；配置仍用 `AT+BATT`/`batt` |
| 设备标识 | `no` 字符串（型号+序号等） | 帧内 **DevAddr 4 字节**；**LoRaWAN DevEUI 8 字节** = 前缀 + 标号（§2.3.1） |
| 空口加密 | TLS/MQTT 等上层 | 私有：`AT+AES` 配 128-bit 密钥（16 字节 hex）；LoRaWAN：入网密钥（AppKey 等，非本 `aes`） |

## 8 规范改动清单（对现有 LoRa）

| 项 | 内容 | 兼容性 |
| -- | --- | --- |
| 保留 | `per`/`var`/`lora`/`exlora`/`ack`/`batt`/`ver`/`log` | 现有固件与 SensorTool 无需变更 |
| 新增 | `cal`、`tun`（先在已有 0x13/0x17 的产品上补 AT） | 旧固件回 ERROR |
| 预留 | `thre`、`acc` | 能力集外 → ERR3 |
| 明确（文档） | LoRa **支持** `unit`/`ran`（压力/液位/拉力等模拟量）；`ran` 用于 ADC 满量程→工程量程量产标定（例 0–3V→1/2/3 MPa） | 与用户口径对齐；**非** ERR3 |
| 明确 | `door`/`io`/`pwr` 归硬件层 | 与现状一致 |
| 上报口径（文档） | **LoRa 空口仅 TLV**；§6.6 重做注册包/数据包设计；删除 JSON 上报示例；保留 §6.6.5 迁移对照；WW-27L 差异见 §6.4 | 新对接按 §6.6；现网 WW-27L 仍可能测量子集（§6.4） |
| 明确（文档） | `aes`（私有 **128-bit 密钥**，非开关）、`eui`/DevEUI（8 字节=前缀+标号）；私有编号 4 字节 | 以 `ATH` 为准；不计入射频固定 4 条 |
| 明确（文档） | **去掉 SL 别名**（门磁/水浸现用 **WW-27L / WW-26L**）；新增 **WW-D5-L** RS485/Modbus AT（`MBUART`/`MBMODE`/`MBCMD`/`MBSCAN`/`MBRAW`）与 TLV **`0x24`** | 以产品页/ATH 为准；MB 参数优先远程 AT，勿臆造寄存器 |
