1配置时机与通道

设备每次上报完成后保持连接监听下行：

项说明
监听窗口TCP 上报成功后保持连接监听 5s（部分产品约 3s，以实际型号说明为准）
下发内容一包 JSON，建议 ≤ 512B（设备接收缓冲 1KB）
编码UTF-8，建议单行
键名不区分大小写（推荐小写）
配置类 value字符串，格式与本地 AT+KEY= 右侧相同；也可用 "?" 查询
设备不是常驻监听端口，仅在上报后的短窗口内可接收下行控制。若需更快响应，可缩短上报周期，或触发一次强制上报。

2JSON 字段表

JSON key对应 ATvalue 示例说明
perAT+PER="60,300"检测秒,上报秒
varAT+VAR="100,500"温/湿变化量（0.01 单位）
threAT+THRE="6000,0" 或 "OFF"阈值或关闭
serverAT+SERVER="TCP,81.71.164.182,20004"类型,主机,端口
mqttAT+MQTT="u,p,cid,topic/sub"MQTT 四段（用户名,密码,ClientId,Topic）
verAT+VER="WW105C,200"须为字符串；下次开机仍被固件覆盖
logAT+LOG="1" 或 1调试日志 0/1
rstAT+RST="24,10,10"复位策略：小时,网络失败次,传感器失败次
tt—1719300000Unix 秒对时

不同型号支持的字段以其产品说明为准；部分压力类遗留键（var / unit / ran / thre）在非压力机型上可忽略。

3配置示例

3.1 修改上报周期

{"per":"610,610"}

3.2 修改阈值并关闭

{"thre":"6000,0"} {"thre":"OFF"}

3.3 修改服务器

{"server":"TCP,81.71.164.182,20004"}

3.4 对时并开启日志

{"tt":1719300000,"log":1}

3.5 组合下发

{"tt":1719300000,"per":"610,610","thre":"OFF","log":1}

只带需要修改的字段即可，无需下发全部配置。

3.6 查询当前配置

下发: {"per":"?"} 设备应答: {"per":"60,600"}

4生效规则与注意事项

项说明
落盘含配置字段 → 写入 RAM 并落盘 UserCfg，掉电保持
对时含 "tt":<unix秒> → 校准设备时间
网络重初始化修改 server / mqtt 后设备会标记网络重初始化，下次上线再发注册包
型号覆盖Flash 或远程修改 ver 仅临时有效，重启恢复固件内置型号
驻网时间每次上报冷启动 4G，驻网可达数十秒～2 分钟，上报周期不宜过短
调试口共用部分产品 BLE 与 USB 调试共 UART，BLE 保持连接时可能抢占串口应答
