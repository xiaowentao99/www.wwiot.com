1简化 JSON 报文

1.1 WW-12C 小白盒温湿度

{ "iccid": "898608321123D1225554", /* 设备 CCID，对接客户平台需记录，充值使用 */ "seq": 306, /* 包序号 */ "imei": "862323085589300", /* 设备 IMEI */ "ts": 1788415298, "batt": 100, /* 电池电量 */ "sn": "08558930", /* 设备唯一编号 */ "csq": 23, /* 信号强度 25~31 优秀，17~24 良好，16 及以下较差 */ "hum": 59, /* 湿度，59% */ "tmp": 291 /* 温度，29.1° */ }

1.2 WW-26C-SP2X 小白盒水浸

{ "csq": 30, /* 信号强度 */ "iccid": "898608321123D1225559", /* 设备 CCID */ "sn": "08558950", /* 设备唯一编号 */ "seq": 200, /* 包序号 */ "imei": "862323085589508", /* 设备 IMEI */ "water": 0, /* 水的状态，有水：1，无水：0 */ "ts": 1788747296, "batt": 100 /* 电池电量 */ }
信号强度 csq 取值参考：25~31 信号优秀，17~24 信号良好，16 及以下信号较差。

2.2 心跳数据

Topic: WW/4G-SMOKE/862856076748666/thing/property/post QoS: 0 {"id":"5","version":"1.0","params":{"TERMINAL_TYPE":"SMOKE","SIGNAL_POWER":10,"BATTERY_VALUE":90}}
字段含义
serviceIdHEARTBEAT 心跳
deviceId设备 ID 号
messageTypepost
payload数据内容
TERMINAL_TYPE设备名称
SIGNAL_POWER信号强度
BATTERY_VALUE电池电量

2.3 报警事件数据

Topic: WW/4G-SMOKE/862856072847785/thing/event/post QoS: 0 {"id":"6","version":"1.0","params":{"ALARM_STATE_REPORT":{"value":{"ALARM_STATE":1}}}} Topic: WW/4G-SMOKE/862856072847785/thing/event/post QoS: 0 {"id":"7","version":"1.0","params":{"SMOKE_DATA_REPORT":{"value":{"TERMINAL_TYPE":"4G-SMOKE_V2.0","SIGNAL_POWER":18,"BATTERY_VALUE":86,"SMOKE_VALUE":168,"ALARM_STATE":1}}}} Topic: WW/4G-SMOKE/862856072847785/thing/event/post QoS: 0 {"id":"8","version":"1.0","params":{"ALARM_STATE_REPORT":{"value":{"ALARM_STATE":0}}}} Topic: WW/4G-SMOKE/862856072847785/thing/event/post QoS: 0 {"id":"9","version":"1.0","params":{"SMOKE_DATA_REPORT":{"value":{"TERMINAL_TYPE":"4G-SMOKE_V2.0","SIGNAL_POWER":18,"BATTERY_VALUE":86,"SMOKE_VALUE":11,"ALARM_STATE":0}}}}
字段含义
ALARM_STATE_REPORT报警事件上报，ALARM_STATE 为 1 报警、0 恢复正常
SMOKE_DATA_REPORT烟感实时数据：TERMINAL_TYPE 产品类型、BATTERY_VALUE 电池电量、ALARM_STATE 报警类型、SIGNAL_POWER 信号强度、SMOKE_VALUE 烟雾值
messageTypeevent

2.4 故障数据

Topic: WW/4G-SMOKE/862856076748666/thing/event/post QoS: 0 {"id":"10","version":"1.0","params":{"TROUBLE_REPORT":{"value":{"TROUBLE":21}}}}
TROUBLE含义
21电池电量低
1传感器故障
101通讯故障

2.5 故障恢复数据

Topic: WW/4G-SMOKE/862856076748666/thing/event/post QoS: 0 {"id":"11","version":"1.0","params":{"TROUBLE_RES_REPORT":{"value":{"TROUBLE":21}}}}

TROUBLE_RES 为 21 电池电量恢复、1 传感器故障恢复、101 通讯故障恢复。

2.6 自检数据

Topic: WW/4G-SMOKE/862856076748666/thing/event/post QoS: 0 {"id":"5","version":"1.0","params":{"SELF_TEST_REPORT":{"value":{"SELF_TEST_MODE":2,"ALARM_STATE":0,"TAMPER_ALARM":0,"SIGNAL_POWER":26,"BATTERY_VALUE":86}}}}
字段含义
SELF_TEST_MODE1 远程自检，2 按键自检
TAMPER_ALARM防拆状态
SIGNAL_POWER信号强度
BATTERY_VALUE电池电量
ALARM_STATE报警状态
SAAS 平台收到数据需回复 HTTP 200。超过 48 小时无任何数据时，平台判断该设备为掉线状态。
