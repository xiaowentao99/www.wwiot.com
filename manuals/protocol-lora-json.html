1简介

该文档介绍 JSON 格式报文及交互流程，适用于 GL6xx 系列网关的通信。目前 JSON 格式最新版本为 1.2.1。

2JSON 格式 1.1.x

2.1 上行数据格式

2.1.1 JSON 字段描述

未说明字段为保留字段，用户可以不用关心。

顶层字段：

关键词描述类型说明
gw网关消息标识对象网关 JSON 数据包含在该字段下

gw 下字段：

关键词描述类型说明
gwid网关地址字符串8 字节十六进制字符串，即 16 个字符
gwpv网关协议版本字符串版本字符串
gwdv网关设备版本字符串版本字符串
gwsq网关包序号数字4 字节无符号整型，由网关生成；操作节点、操作网关流程中取下行数据的 gwsq 字段
gwifty网关消息类型数字0 射频包数据 / 1 网关配置回复 / 2 4G 终端 / 99 网关心跳报文 / 100 网关注册报文
gwak网关配置回复数组只在 gwifty 为 1 时有效
rxpk射频包数据数组只在 gwifty 为 0 或 10 时有效

gwak 下字段：

关键词描述类型说明
gwakob执行对象字符串值为定义的执行对象字符串
gwakrt执行结果数字0 执行成功，1 执行失败
gwakif附带信息字符串预留

rxpk 下字段：

关键词描述类型说明
tmst时间戳字符串射频计时器值
time接收时间字符串合法的时间戳字符串，单位为秒
chan信道号数字无符号整型
freq频点数字单位 Hz
foff频偏数字1.1.0 协议版本支持，有符号整型，单位 Hz
rssi信号强度数字有符号整型，单位 dBm
lsnr信噪比数字浮点型
rfch通道号数字无符号整型
stat状态数字无线 CRC 状态
modu调制模式字符串LORA、FSK
datr扩频因子字符串SF5 ~ SF12
codr编码率字符串4/5、4/6、4/7、4/8
pksz数据包长度数字无符号整型，不超过 256
pkdt数据包内容字符串十六进制字符串，长度为 pksz*2

2.1.2 实例数据

实际网关报文为节省长度做了压缩处理，去掉不必要换行和空格，但 JSON 含义不变。实际报文展示如下：

{"gw":{"gwid":"231809d75a9e9b0a","gwpv":"1.0.0","gwdv":"1.0.6","gwsq":40,"gwifty":0,"rxpk":[{"tmst":"751007902","time":"1610335333","chan":3,"freq":476100000,"rssi":-67,"lsnr":7.5,"rfch":0,"stat":16,"modu":"LORA","datr":"SF12","codr":"4/5","pksz":32,"pkdt":"030f354cde000023000e210103ff300000ff5082040000050008000000001f4a","ndty":1}]}}

多包数据示例：

{ "gw": { "gwid": "3c1809d75a9e9b0a", "gwpv": "1.0.0", "gwdv": "1.0.5", "gwsq": 2, "gwifty": 0, "rxpk": [{ "tmst": "30846567", "time": "1607408329", "chan": 7, "freq": 476900000, "rssi": -73, "lsnr": 5.75, "rfch": 1, "stat": 16, "modu": "LORA", "datr": "SF7", "codr": "4/5", "pksz": 13, "pkdt": "03070f180c00293b0020048d02", "ndty": 1 }, { "tmst": "30846567", "time": "1607408329", "chan": 7, "freq": 476900000, "rssi": -73, "lsnr": 5.75, "rfch": 1, "stat": 16, "modu": "LORA", "datr": "SF7", "codr": "4/5", "pksz": 30, "pkdt": "0300000576000097004c2001000007fff900f5000300000400a605319104", "ndty": 1 }] } }

报文表示网关 ID 为 3c1809d75a9e9b0a，收到 2 包射频数据包：第 1 包长度 13 字节，内容为 03070f180c00293b0020048d02；第 2 包长度 30 字节，内容为 0300000576000097004c2001000007fff900f5000300000400a605319104。

网关心跳与配置回复示例：

{ "gw": { "gwid": "231809d75a9e9b0a", "gwpv": "1.0.0", "gwdv": "1.0.5", "gwsq": 2, "gwifty": 99 } }

2.2 下行数据格式

gw 下字段：

关键词描述类型说明
gwid网关地址字符串8 字节十六进制字符串
gwpv网关协议版本字符串版本字符串
gwdv网关设备版本字符串版本字符串
gwsq包序号数字4 字节无符号整型，其值由发送端生成
gwifty消息类型数字0 表示节点配置，1 表示网关配置
gwcfg网关配置对象只在 gwifty 为 1 时有效
ndcfg节点配置数组只在 gwifty 为 0 时有效，值为十六进制字符串数组。数组长度不超过 32，单条数据不超过 255 字节

3JSON 格式 1.2.x

本章节主要描述相对于 1.1.x 版本的修改，着重描述差异部分，相同部分不做重复说明。

3.1 上行数据格式

3.1.1 整体数据格式

{ "gw": { "gwid": "", "gwpv": "", "gwdv": "", "lati": 0, "long": 0, "gwsq": 0, "gwifty": 0, "rxpk": [{ "is_cache": 0, "tmst": "", "time": "", "chan": 0, "freq": 0, "foff": 0, "rssi": 0, "lsnr": 0, "rfch": 0, "stat": 0, "modu": "", "datr": "", "codr": "", "pksz": 0, "pkdt": "", "sensor": { "version": 0, "device_no": "", "seq": 0, "...": "" } }] } }

3.1.2 变动字段描述

相对于 1.1.0 版本：顶层字段添加 lati、long 字段，为网关经纬度信息；gw 下字段、gwak 下字段没有变化；rxpk 下字段添加 sensor 字段，删除保留字段 ndifty，其他字段没有变化。

关键词描述类型说明
lati网关纬度数字可配置静态经纬度信息；如果网关有卫星定位功能则上报获取的经纬度信息
long网关经度数字经度信息
is_cache离线缓存标记数字0 表示实时数据，1 表示离线缓存数据（1.2.1 版本支持）
sensor传感器内容对象扩展项，网关能够解析传感器则有，否则无

3.1.3 sensor 下公共字段

公共字段是所有传感器可以使用的字段，并非每次数据上报都包含所有字段。

关键词描述说明
version协议版本传感器报文协议版本，一般为 3
device_no设备编号4 个字节十六进制字符串
seq包序号0-65535 依次递增循环使用
firmware设备版本0-7 依次递增循环使用
battery电量0-100
device_type设备类型不同类型传感器的值不同
is_abnormal设备/数据异常0 正常，1 异常
freq_tx用户参数，发送频点单位 Hz
sf_tx用户参数，发送扩频因子
preamble_rx用户参数，接收前导长度
period_detect用户参数，检测周期单位秒
period_report用户参数，上报周期单位秒
calibration用户参数，校准值
parameter_var1~5用户参数，变量 1~5
ack_type应答命令回复操作类型
ack_result应答结果0 失败，1 成功

3.1.5 sensor 下通用字段

设备类型无匹配时，使用以下字段：acce_event、acce_x、acce_y、acce_z、longitude、latitude、adc、temperature、humidity、concentration、pressure、sense、sense_unit、switch_status、angle_x、angle_y、angle_z、multi_adc、multi_temperature、multi_humidity、multi_concentration、multi_pressure、multi_sense、multi_switch、electricity、voltage、active_power、user_data、modbus_data、command_index、command_data、ch4_lel、co_ppm、h2s_ppm、co2_ppm、nh3_ppm、instrument_address。

3.1.7 4G 烟感 MQTT 报文（WW-22C）

心跳数据：payload 含 TERMINAL_TYPE、SIGNAL_POWER、BATTERY_VALUE。

报警事件：ALARM_STATE_REPORT 与 SMOKE_DATA_REPORT，ALARM_STATE 为 1 报警、0 正常，SMOKE_VALUE 为烟雾值。

故障数据：TROUBLE_REPORT，TROUBLE 为 21 电池电量低、1 传感器故障、101 通讯故障。

故障恢复：TROUBLE_RES_REPORT，TROUBLE_RES 对应 21 电池电量恢复、1 传感器故障恢复、101 通讯故障恢复。

自检数据：SELF_TEST_REPORT，SELF_TEST_MODE 为 1 远程自检、2 按键自检，另含 TAMPER_ALARM、SIGNAL_POWER、BATTERY_VALUE、ALARM_STATE。

SAAS 平台收到数据需回复 HTTP 200。超过 48 小时无任何数据时，平台判断该设备为掉线状态。
